先统一奇偶两种中心

符号与边界约定
p[i]
从 i 向一侧延伸的格数。中心本身占 0 格，覆盖 [i−p[i], i+p[i]]。
C
当前已知、右端最靠右的回文中心。
R
这个回文的右端下标，包含该位置。左端 L = 2C−R。
j
i 关于 C 的镜像下标，j = 2C−i。
插入分隔符有什么作用

aba → ·a·b·a·，中心落在 b。abba → ·a·b·b·a·，中心落在两个 b 之间的 ·。

原串的每个字符和每个间隙都有了中心位置，扩展时都比较左右相同距离的两格。浅灰 · 是独立存储的虚拟分隔符。

怎样映射回原字符串

变换串中 [i−p[i], i+p[i]] 对应原串长度 p[i]，起点为 ⌊(i−p[i])/2⌋。

上方原串的蓝色区域跟随当前半径，底部记录已完成中心中找到的最长回文。长度相同时保留最靠左的一个。

镜像能借多少

当 i < R 时，i 和 j 都在以 C 为中心的已知回文内。左右字符对称，让 j 已算出的半径成为 i 的起点。

j = 2C − i p[i] = min(p[j], R − i)

完整落在内部

p[j] < R − i

镜像回文及其下一对不等字符都在 [L, R] 内。它们一起被映射过来，所以 p[i] 就等于 p[j]。

恰好到达边界

p[j] = R − i

已知部分可以完整借用。下一对涉及 R 外的字符，需要实际比较，成功时继续扩展。

镜像半径跨过边界

p[j] > R − i

先借到 R，得到 p[i] = R−i。统一流程的下一次检查会遇到不相等或越界，半径停在这里。

跨界时为什么会停止

C 的回文已经扩展到最大。如果两端仍有字符，则 T[L−1] 与 T[R+1] 不相等。

跨界的镜像回文将 T[L−1] 对应到大回文内部，再关于 C 反射，恰好得到 i 下一对的左字符。因此它与右字符 T[R+1] 不相等。

把工作量记在右边界上

  1. 外层从左到右处理 m 个中心，每次借半径只做常数次运算。
  2. 借用以后，每次成功比较都探到旧 R 右侧的一个新位置。本轮结束时，再把 R 更新到最右端。
  3. R 单调右移，成功比较总共至多 m−1 次。每个中心至多有一次失败比较，总共至多 m 次。
m = 2n + 1 总字符对比较 < 2m 时间 O(n) · 空间 O(n)
