i、j 和 mid 表示什么

i 是 A 挡板左侧的元素个数，j 是 B 挡板左侧的元素个数。两者相加始终为 mid = ⌈(m+n)/2⌉。

总长度为偶数时两半等长，为奇数时左半部分多一个元素。移动 i 后，用 j = mid−i 同步移动另一个挡板。

方向来自数组有序

每个数组内部，挡板左边的元素都小于等于右边。再满足两条交叉比较，就能保证合起来的左半部分小于等于整个右半部分。

a_left > b_right

A 左边放进了过大的元素。i 增大时，a_left 会增大或持平，j 会减小，使 b_right 减小或持平。因此 i 及其右边的位置都可排除。

r = i − 1

b_left > a_right

B 左边的最大值超过了 A 右边的最小值。i 减小时，a_right 会减小或持平，j 会增大，使 b_left 增大或持平。因此 i 及其左边的位置都可排除。

l = i + 1
区间大小与复杂度

每次缩区间都排除中点及一侧的候选位置。迭代数为 O(log(K+1))，算法维护挡板、边界值等固定个变量，额外空间为 O(1)。

对应你写的 Rust

let mid = (m + n).div_ceil(2);

div_ceil 把除法结果向上取整。例如总长 5 时 mid = 3，左边容纳 3 个元素。

let mut l = mid.saturating_sub(n);
let mut r = m.min(mid);

由 0 ≤ i ≤ m 和 0 ≤ mid−i ≤ n，得到 max(0, mid−n) ≤ i ≤ min(m, mid)。

saturating_sub 在结果应小于 0 时返回 0，适合这里的无符号长度。

let mut i = (l + r) / 2;
let mut j = mid - i;

整数除法向下取整来选中点。i、j 都计数挡板左边的元素个数，位置 0 与数组长度都是合法挡板。

i32::MIN / i32::MAX

你的代码用两个极值代表空侧。动画显示为 −∞ 与 +∞。演示数值采用题目范围 [−10⁶, 10⁶]，让空侧始终自然满足对应比较。
